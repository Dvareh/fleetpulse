# FleetPulse - Fleet & Vehicle Maintenance Management (MVP)

A full-stack web application designed for managing company vehicle fleets, tracking maintenance logs, and calculating operational analytics with predictive service scheduling.

## Tech Stack
- **Backend:** Java 21, Spring Boot 3, Spring Data JPA, H2 Database (In-Memory), Swagger/OpenAPI.
- **Frontend:** Angular, TypeScript, Pure CSS.

## Architecture
- `/backend` - RESTful API with layered architecture (Controller, Service, Repository, DTO).
- `/frontend` - Single Page Application (SPA) with responsive design.
